# Saleh Ayman — Portfolio

Personal portfolio of **Saleh Ayman**, a cybersecurity engineer exploring SOC operations, incident response, red teaming and offensive security.

**Live site:** https://saleh-ayman.github.io

## About this project

A fast, single-page portfolio built with plain HTML, CSS and JavaScript. There are no frameworks, no build step and no trackers, so the whole site is one file that loads quickly and is easy to audit.

## What's inside

- **Hero:** glowing name, a typewriter line, and an animated terminal that introduces me
- **Summary strip:** a moving band with a quick overview of what I do
- **Selected work:** filterable project cards
  - VIGIL: an AI-assisted SOC triage assistant
  - SIEM Detection Engineering, Alert Triage and SOC Operations
  - Python scripting and automation
  - Smart Living Advisor
- **Skills:** a branching tree covering SOC and detection, incident response, offensive and red team, networking, and engineering
- **Journey:** a timeline of education, training and freelance work
- **Learning in public:** write-ups, TryHackMe, Hack The Box and Medium
- **Experience details:** light and dark themes that remember your choice, a responsive layout, and reduced-motion support

## Tech

- HTML5 and CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript
- Google Fonts (Fraunces, Inter, JetBrains Mono), the only external resource

## Project structure

```
.
├── index.html   # the whole site: markup, styles and scripts
└── README.md
```

## Customize

Everything lives in `index.html`:

- **Colors and themes:** the CSS variables at the top of the `<style>` block.
- **Projects:** the cards inside the `#work` section.
- **Skills:** the branches inside the `#skills` section.
- **Journey:** the timeline items inside the `#journey` section.

## Security and privacy

This is a static site with no backend, forms, cookies or analytics. The only data stored in the browser is the chosen theme (`localStorage`), and the only third-party request is Google Fonts.
